1. 先用一句话理解

Hamdoku 是一款按行、列、颜色区域和相邻限制放置仓鼠的逻辑解谜游戏。玩家先排除不可能的格子，再逐步确定仓鼠位置，直到满足整张棋盘的约束。

棋盘以不规则色块划分区域。颜色和区域图案帮助识别归属；“×”用于记录推理，仓鼠代表已经确定的位置。难点来自多个条件交叉，而不是数字计算。

观察色区→标记排除→确定仓鼠→检查剩余空间→全部找到 → 结算

2. 三条规则必须同时成立

原作文案

每个区域一只

每个颜色区域只能有一只仓鼠。放置后，同区域的其他格子都不能再放。

原作文案

每行、每列各一只

一只仓鼠同时占用所在行与列。目标是完成所有行列，不是只填满某一个色区。

原作文案

不能紧挨，包括斜角

周围八个相邻格都不能再放仓鼠。不同颜色、不同列的斜角邻格也会冲突。

交互示意：检查一个候选格

固定仓鼠在第1行第2列。点选其他格子，查看它与固定仓鼠的约束关系。

此示意使用原作 Campaign 样例0的4×4区域与答案 [1,3,0,2]，仅演示三条约束。候选格暂不冲突不等于它就是答案；本示意不复现原作输入、扣生命或完整求解器。

待核实原作是否在落子时检查预设答案、只检查即时冲突，或执行更深层可解性验证，需要进一步核对原作判定逻辑与运行过程。不能把当前复刻代码的选项视为原作事实。

3. 玩家操作与首次教学

操作原作表达分析与验证边界
双击格子“点两下放上仓鼠吧”确认仓鼠位置。双击时间阈值、已标记格及已放置格的再次操作仍需逐项运行核对。
单击空格“点一下空格，一格一格标记起来”用于记录排除；与放置仓鼠区分，支持逐格推理。
滑过多个格子“滑过这些格子标记起来”减少重复点击；拖动阈值、跨越已放置格与重复经过的行为待精确验证。
请求提示“点这里获取提示”在学习规则后介绍辅助入口；两种道具的具体效果与消耗链不能只按图标推断。

教学文案覆盖放置、排除、行列/区域/邻格规则，再让玩家寻找最后的仓鼠。原作另有 Tutorial_4x4 静态配置；教程与主线样例0是不同布局，不能混用。现有工作记录确认约96秒录像包含教程和前几关操作，录像尚未正式归档到本库。

依据：tut_do_place、tut_do_tap_x、tut_do_drag_x、tut_solve_self、tut_hint_avail；录像来源与已查看范围。

4. 生命、道具与失败补救

系统可确认的资料仍需核对的行为
生命预算GameConfig.maxHearts = 3；棋盘截图显示三颗生命种子。每种错误的扣除时机、重复误触处理、重新开始与跨局恢复。
两种辅助道具配置 hintsPerLevel = 3、autoCrossPerLevel = 3；文案及商品区存在放大镜与提示。字段与显示名称的最终映射、每局额度与持有库存关系、自动排除与提示效果、广告补充与持久化。
生命耗尽截图出现“葵花籽用完了”、AD标记、“获得3颗葵花籽”及“重新开始”。广告成功、取消、失败的结果；是否保留已填棋盘、计时及道具；重新开始确认。
辅助推荐配置 itemNudgeIdleSec = 12、itemNudgeIdleSecAfterMistake = 6、itemNudgeMaxPerPuzzle = 3。这些是静态字段值，不能据此断言实际触发顺序、推荐次数或动画已经运行验证。
生命HUD与奖励文案都使用种子意象。是否共享同一余额或分别属于局内容错、结算资源，必须按状态流核对，不能只凭相似图标合并成一个经济系统。

依据：原作 GameConfig 快照、耗尽提示原图。

5. 从一关解谜，到长期目标

主线提供持续推进；每日挑战与连胜引导回访；排行榜提供比较目标；个人资料承载统计与装扮。以下数值都是提取包中的配置，运行时条件、远端覆盖与结算时点仍需确认。

系统静态配置 / 画面依据策划作用与边界
主线首页关卡入口；Campaign 样例含区域与每行答案列。逐关推进。文件序号不能直接等同原作运行关号；随机池、难度调节和首批选图待核对。
排行榜rankingUnlockClears = 10；rankingGroupSize = 50；已有前三名与个人行截图。提供阶段目标。配置还含 rankingDummy* 字段，静态画面不能证明榜单是真实联网排名或说明其全部数据来源。
每日挑战dailyUnlockClears = 20；dailySize = 7；dailySeasonPieces = 30。固定日程与收集目标。补签、重试、日期切换和季节拼图的完整流程待验证；dailyRetryMaxPerDay = 0 的语义不作推断。
每日连胜streakCycleDays = 7；已归档幼苗、连胜天数与七天奖励画面。将回访转为可见成长。配置含10/14/21/30等成长字段，实际植物阶段、领奖与断签恢复待核对。
无限模式endlessUnlockClears = 100；endlessStartSize = 5；endlessMaxSize = 10；endlessStepEvery = 3。延长核心解谜体验。缺少实机模式画面，不直接把字段组合成已确认的扩盘时序。
商店与个人资料已有商品、头像、边框、服装与统计截图；ShopCatalog 有独立快照。消耗补给与个性化展示。购买、恢复购买、解锁、佩戴以及平台服务均未据此验证。

依据：GameConfig、ShopCatalog与下方原图。
